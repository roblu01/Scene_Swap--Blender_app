Scene Swap 1.0

This is a small application for blender. it seamlessly hides (viewport view and render view) assets (objects, meshes, lights, cameras) in worlds/scenes that the user manually puts in. It is a great way to switch between scenes without opening a new .blend file or manually hiding assets one by one.

How to run the app

This application needs Pyside to run. Move the folder at blender's startup, usually at:
C:\Users\USER\AppData\Roaming\Blender Foundation\Blender\VERSION\scripts for WINDOWS 
or /Applications/Blender.app/Contents/Resources/5.2/scripts/startup for MACOS
 
the Python file "scene_swap_startup.py" needs to be moved outside the folder to be inside blender's startup folder so it can be executed directly by blender.
